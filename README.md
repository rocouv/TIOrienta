# TI Orienta

Test vocacional de 24 preguntas para descubrir rutas concretas dentro de tecnología: frontend, backend, UI/UX, datos, docencia tecnológica y soporte IT.

El motor entrega un perfil principal, secundario y tercero. Si los dos primeros tienen una afinidad cercana, muestra una orientación híbrida como `UI Developer`, `Instructor de programación` o `Desarrollo full-stack`.

## Desarrollo

```bash
bun install
bun run dev
```

Para ejecutar las pruebas del motor:

```bash
bun test
```

El resultado se calcula completamente en el navegador. No se guardan respuestas ni datos personales.
